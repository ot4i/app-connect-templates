This flow retrieves New Relic issues and transaction error data using a custom NRQL query when an alert event occurs, and sends an email via Gmail.

1. Click **Use this template** to start using the template.
2. Click the **New Relic** node, and if you're not already connected, connect to your [New Relic account](https://ibm.biz/acnewrelic).
3. Click the **Gmail** node, and if you're not already connected, connect to your [Gmail account](https://ibm.biz/acgmail).
4. In the **Gmail Send email** action, update the **To** field with the recipient email address.
5. To start the flow, in the banner, click **Start flow** or **Deploy flow**.

Use this template to retrieve New Relic issues and transaction error data using NRQL when an alert event occurs and send an email via Gmail.
