This template summarizes new ServiceNow incident tickets by using Amazon Bedrock (Amazon Nova Pro model) and sends the summary by email via Gmail. When a ticket is created, the flow sends the ticket details to Amazon Bedrock, which generates an analysis that covers the incident summary, business impact, likely root cause, recommended resolution steps, and a customer-facing response. The flow then sends the summary to the person who opened the ticket.

To refer to these instructions while editing the flow, open [the GitHub page](https://github.com/ot4i/app-connect-templates/blob/main/resources/markdown/Summarize%20a%20new%20ServiceNow%20incident%20using%20Amazon%20Bedrock%20and%20send%20a%20Gmail%20message_instructions.md) (opens in a new window).

1. Click **Use this template** to start using the template.
2. Connect to the following accounts by using your credentials:
   - [ServiceNow](https://ibm.biz/acservicenow)
   - [Amazon Bedrock](https://ibm.biz/acawsbedrock)
   - [Gmail](https://ibm.biz/acgmail)
3. To start the flow, in the banner, click **Start flow**.
