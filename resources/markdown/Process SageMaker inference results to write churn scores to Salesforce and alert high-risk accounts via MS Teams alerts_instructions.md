To refer to these instructions while editing the flow, open the [GitHub page](https://github.com/ot4i/app-connect-templates/tree/main/resources/markdown/Process%20SageMaker%20inference%20results%20to%20write%20churn%20scores%20to%20Salesforce%20and%20alert%20high-risk%20accounts%20via%20MS%20Teams%20alerts_instructions.md) (opens in a new window).

1. Click **Use this template** to start using the template.
2. Connect to the following accounts by using your credentials:
   - [Amazon Eventbridge](https://ibm.biz/acamazoneventbridge) 
   - [Amazon S3](https://ibm.biz/acamazons3)
   - [Salesforce](https://ibm.biz/acsalesforce)
   - [Microsoft Teams](https://ibm.biz/acmsteams)

3. To start the flow, in the banner, click **Start flow**.

Use this template to process SageMaker inference results to write churn scores to Salesforce and alert high-risk accounts via MS Teams alerts.
