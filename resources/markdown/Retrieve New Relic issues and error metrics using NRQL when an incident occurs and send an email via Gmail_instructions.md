To refer to these instructions while editing the flow, open [the GitHub page](https://github.com/ot4i/app-connect-templates/blob/main/resources/markdown/Retrieve%20New%20Relic%20issues%20and%20error%20metrics%20using%20NRQL%20when%20an%20incident%20occurs%20and%20send%20an%20email%20via%20Gmail_instructions.md) (opens in a new window).

Use this template to retrieve New Relic issue details and run a custom NRQL (New Relic Query Language) query to gather error count and error rate metrics for the affected entity when a New Relic alert event occurs. The results are sent as an email via Gmail.

1. Click **Use this template** to start using the template.
2. Click the **New Relic** node, and if you're not already connected, connect to your [New Relic account](https://ibm.biz/acnewrelic).
3. Click the **Gmail** node, and if you're not already connected, connect to your [Gmail account](https://ibm.biz/acgmail).
4. In the **Gmail Send email** action, update the **To** and **CC** fields with the recipient email addresses.
5. To start the flow, in the banner, click **Start flow**.
