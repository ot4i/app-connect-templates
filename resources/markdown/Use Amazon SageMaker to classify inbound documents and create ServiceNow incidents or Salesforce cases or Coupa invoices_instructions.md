To refer to these instructions while editing the flow, open the [GitHub page](https://github.com/ot4i/app-connect-templates/tree/main/resources/markdown/Use%20Amazon%20SageMaker%20to%20classify%20inbound%20documents%20and%20create%20ServiceNow%20incidents%20or%20Salesforce%20cases%20or%20Coupa%20invoices_instructions.md) (opens in a new window).

1. Click **Use this template** to start using the template.
2. Connect to the following accounts by using your credentials:
   - [Amazon SageMaker](https://ibm.biz/acamazonsagemaker) 
   - [Gmail](https://ibm.biz/acgmail)
   - [ServiceNow](https://ibm.biz/acservicenow)
   - [Salesforce](https://ibm.biz/acsalesforce)
   - [Coupa](https://ibm.biz/accoupa)
3. To start the flow, in the banner, click **Start flow**.

Use this template to use Amazon SageMaker to classify inbound documents and create ServiceNow incidents or Salesforce cases or Coupa invoices.
